# 任务 C：超长单题跨页方案（仅评估）

推荐方案 3：超长题从新页开始，在合法段落或小问边界续页，并标注“（续下页）”。普通题继续整题分页。最终页数仍以当前导出件的像素预览为依据；方案 2 的浏览器拆页本身无法保证与 Word/WPS 页数一致。

## 现状与问题边界

核查当前代码：`livePreview/blocks.tsx` 把题干、图片、答案和解析组合成整题块；`usePagination.ts::paginate` 让超过正文页高的整组进入单页并标记 `overflow`；`PageView.tsx` 使用固定纸高，`livePreview.css` 设置 `overflow:hidden`。`LivePreviewPanel.tsx` 已有“约 N 页（含长题，最终以导出为准）”及 tooltip。

因此，已知样本少一页并不是“所有超长题固定少一页”；多页解析可能产生更大差异，结构预览还可能裁掉后半内容。只增加页码或 tooltip 不能保证教师完整检查长题。以下为代码阅读推导，未新增分页原型或假称完成新的 Word/WPS 排版验收。

## 三方案比较

| 方案 | 分页与内容 | 教师影响 | 实现代价（含验证） | 强制预览门禁 |
|---|---|---|---|---|
| 1. 保持整题不拆 + 现有 tooltip | 延续近似页数；超长块可能溢出、被固定纸高裁切 | 操作习惯不变；需要主动看像素预览才能确认后半内容，单靠结构视图容易漏检 | 保持现状 0 人日；若加强常驻溢出提示约 0.5–1 人日，仍不解决断页 | 正常仍须当前像素预览成功；环境降级时结构确认可能面对未完整可见的题，应明确显示未核验范围，不能暗示精确分页 |
| 2. 超长题允许直接拆页 | 可以按行/段跨页，页数较接近实际；若采用高度切片会截断公式、表格或图片。不能把 CSS 裁切当作完成分页 | 版面紧凑，但题干和解析阅读连续性较弱；硬切片会影响理解 | 合法段落分片约 3–5 人日开发 + 2–4 人日验证；精确行级约 8–15 人日以上 | 结构重排本身不解锁；若改变导出断页策略则必须作废旧像素预览与降级确认并重生成；有裁切/内容缺失不能确认“完整检查” |
| 3. 超长题另起页 + 续页标记 | 长题从新页开始；题内按合法断点分片，必要时超过两页，每个非末片标注“（续下页）”；不承诺与所有 Office 引擎完全同页 | 易定位整题及续页，减少把续页当新题；可能增加留白和总页数 | 约 5–8 人日开发 + 3–5 人日验证；若导出也加逐页续页标记，需额外验证 Office 分节/页脚和模板兼容性，约 2–4 人日 | 导出与结构预览必须采用已确认的一致策略；内容、模板、答案模式或分页策略变动后重新锁定；完成全部续页阅读才能做降级确认 |

均为现有代码基础上的工程估算，不是实测工期或交付承诺。选择方案 3 的理由是教师能清楚识别题目边界和后续内容，普通短题的编辑方式保持一致；若长题非常少且接受像素预览等待，可暂用方案 1。

“题目被截断”需区分“完整内容分布在连续页”与“裁掉部分内容”。方案 2 的合理实现应属于前者；丢字、丢图、截半公式不能作为可接受的精确页数交换条件。若必须精确对应某次 Word 导出，复用该次实际渲染的像素页，而不是依据 `ceil(题高/页高)` 宣称精确。

## 推荐方案的实现边界（待确认）

1. 判断正文可用高度，等字体与图片加载完成后测量。仅超长题使用分片；片段沿用同一试卷 item id 和题目快照版本，不向数据库插入“续页题”。首片显示题号和分值，后续片显示“第 X 题（续）”；每个非末片在页脚区显示“（续下页）”。
2. 优先在小问、自然段、答案与解析段落之间断开；公式、图片和不可拆表格行保持原子。单个原子元素本身超页时明确提示，使用实际 Office 预览确认，不裁切冒充完成。分页预算包括页脚与续页标记占用高度。
3. 长题先另起页，结束页剩余空间是否允许下一道普通题紧跟，建议允许以减少留白；这个规则需与导出模板共同确认。大题标题与首片保持相邻，避免孤标题。
4. 拖拽、删题、设分、调序仍作用于整题，多个片段只能有一个可排序身份，不能重复生成相同拖拽 id。片段内容不重复、顺序不变；从答案解析版切回学生版要重新测量。
5. 若续页标记只出现在结构预览，必须标明它是阅读提示，不能让教师以为 DOCX 同样包含；若要求 DOCX 也标记，则需专门授权修改冻结导出文件，并核查逐页条件页脚如何实现，不能把“题目结束段”当真实页脚。本轮没有修改冻结文件。

## 与现有门禁的交互

当前 `uiStore` 门禁按试卷保存会话态，使用 revision 和答案模式/模板 settings key；抽屉与导出中心共用。仅匹配当前请求版本的像素预览完成才解锁；环境失败允许用户确认结构预览后降级；刷新默认锁定。

方案 1 不因看到 tooltip 自动解锁。方案 2/3 若只是改善结构显示，也不把“测量完成”当像素预览成功。若增加影响导出的分页设置，必须把设置加入预览凭据和缓存标识，并在变化时 `invalidatePreview`；过期或迟到任务不能解锁新设置。降级确认应明确“尚未核对实际分页”，并确保长题的所有片段可见；有缺失片段、加载失败或原子块裁切时，不能标记完整阅读。是否允许用户在明确未核验提示后仍导出 DOCX，需要产品决策，本轮不改变现有逃生逻辑。
