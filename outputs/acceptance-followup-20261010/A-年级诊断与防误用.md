# 任务 A：年级诊断与防误用（已完成）

实测缺失年级的 6,549 道题无法从来源文件名可靠补全。本轮增加检索结果区的上下文计数和查看入口，不修改交付数据库，不推断年级或难度。

## 诊断依据与可信度

读取全部 209 个来源（含 4 个没有题目的来源），逐条检查 `source_files.file_name`，同时运行既有 `enrich.infer_grade(filename, None, None)` 与额外显式模式检查。显式模式覆盖“八年级下”“八年级下册”“八年级下学期”“八下”“2026八上”、七/九年级及数字写法、初一至初三、高一至高三与必修册次。不是用文件名未命中旧解析器直接断定不能解析。

| 口径 | 总量 | 文件名有明确年级证据 | 比例 |
|---|---:|---:|---:|
| 年级缺失来源 | 165 | 0 | 0.0% |
| 上述来源所含题目 | 6,549 | 0 | 0.0% |

逐来源文件名、原年级、教材、`grade_source`、`textbook_source`、题量、解析器返回及显式命中记录均保存在 [CSV](<D:/Open-source project/Localtopic-management/outputs/acceptance-followup-20261010/A-逐来源年级诊断.csv>)，统计见 [JSON](<D:/Open-source project/Localtopic-management/outputs/acceptance-followup-20261010/A-年级诊断.json>)。依据是入库来源记录，不是重新扫描预处理目录或猜测题干所属年级；这能证明现有文件名不足以回填，不能证明每份原文都无法经教研人员确认。地区、中考、年份、知识点以及既有教材名均未作为年级证据；没有新增 `filename_parsed` 值。

## 实现与使用效果

选定具体年级时，既有 `/api/search` 响应新增 `grade_gap={selected_grade,count}`。计数保留关键词、学段、学科、教材、章节、题型、难度、题目分组、答案/解析、公式复核、其他缺失桶和知识点严格模式，只把具体年级替换为年级缺失条件；计数独立于分页。复用现有检索函数，原结果、排序、分页没有混入未知年级题。

结果区在正数计数时展示警示及“查看未标注年级的题”。提示明确这些题不代表属于所选年级。点击清除具体年级、启用年级缺失桶、回到第一页，并保留其他条件与严格模式。无年级筛选、已选缺失桶、计数为零、请求进行中或旧分页占位数据时不显示旧提示。原全库覆盖率提示仍说明全库情况，新提示说明当前检索情况。

| 真实库条件 | 原结果 | 提示未标注题 | 点击后结果 | 独立 SQL |
|---|---:|---:|---:|---:|
| 八年级下册 | 1,342 | 6,549 | 6,549 | 6,549 |
| 八年级下册 + 浮力 | 171 | 631 | 631 | 631 |
| 九年级 + 压强 + 有答案 | 0 | 865 | 865 | 865 |
| 八年级下册 + 浮力 + 教材缺失 | 15 | 631 | 631 | 631 |
| 八年级下册 + 浮力 + 已确认知识点 | 0 | 0（隐藏提示） | 0 | 0 |

独立 SQL、绑定参数、完整 API 对照及耗时见 [真实库验证](<D:/Open-source project/Localtopic-management/outputs/acceptance-followup-20261010/A-真实库API验证.json>)。SQL 直接计数并用 FTS 子查询和严格模式 EXISTS 交叉核验，未通过调用同一个计数函数伪装独立对照。

在本机对“八年级下册 + 浮力”各运行 20 次，原检索中位数 5.50ms，增加计数后 8.41ms。是热缓存单机微基准，不代表多用户性能；新增成本是选定年级时的一次缺失题计数及 LIMIT 0 查询，无额外前端网络请求。
