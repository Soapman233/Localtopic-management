# 题库 Web 界面 · 使用说明

> 面向使用它的老师。**不需要懂命令行，也不需要装 Node。**

- 版本：Web 界面 v1（9 个页面全部可用）
- 本轮验证（2026-10-11）：后端 360 项（359 通过、1 项跳过），前端 26 项通过；交付样例卷 #1 三模式导出 + Word/WPS 逐页渲染已通过，详见 `../handoff/D-导出P0最终交接.md`。
- 部署形态：**纯本地单机** —— 服务只跑在你自己的电脑上，不联网、不需要账号

---

## 一、怎么启动

**双击项目根目录的 `启动题库.bat`。**

脚本会自动完成：选 Python 解释器 → 检查数据库 → 检测环境（editor_sdk / Word / WPS）→ 启动服务 → 自动打开浏览器。

启动后浏览器会打开 `http://127.0.0.1:8720`。**关掉那个黑窗口就是关闭服务。**

### 启动时可能看到的环境自检

```
[题库] 环境自检：
[题库]   - editor_sdk：可用（端口 39099）
[题库]   - Word：可用；WPS：可用
```

- **editor_sdk 不可用** → 「像素级预览」和「导出」用不了（导出依赖它）
- **Word/WPS 都不可用** → 会自动降级为「只导 DOCX，不导 PDF」，并给出提示
- 这两种情况都不会静默失败，会明确告诉你

## 二、九个页面各做什么

### 日常最常用的四个

| 页面 | 用途 |
|---|---|
| **检索** | 按关键词 + 左侧筛选找题。结果卡上有答案/解析/难度/待复核徽章 |
| **单题详情** | 看题干（公式已渲染成真公式）、图片、答案、解析、来源；**可以在这里直接改题** |
| **组卷** | **左题库、右试卷双栏**。左边找题点「加入」，右边实时看到整卷、调顺序、设分值、分大题 |
| **导出** | **先预览再导出**。预览是像素级的，所见即所得；支持学生版/答案解析版/仅答案 × DOCX/PDF × 三种模板 |

### 数据治理用的五个

| 页面 | 用途 |
|---|---|
| **知识点复核** | 按标签汇总（183 个），确认/否决；可导出 CSV 离线填好再导入 |
| **待复核公式** | 196 条公式可能有问题，在这里逐条处理 |
| **来源文件** | 209 份源文件；可补年级/教材（**会提示影响多少道题**） |
| **题库统计** | 各维度分布与覆盖率 |
| **系统设置** | 数据库路径、默认导出目录/模板、界面偏好 |

待复核公式页现在可直接查看源公式预览图、题干和当前公式。主色及深色模式在保存设置后全局生效。导出解锁只适用于已预览的内容、答案模式和模板，修改后需重新预览。

## 三、组一份卷的完整流程

```
① 双击 启动题库.bat
② 进「检索」页 → 搜关键词（如「浮力」）→ 左侧筛选收窄范围
③ 点结果卡「加入」→ 右侧试卷实时出现这道题
   （也可以进「组卷」页，左栏检索、右栏整理）
④ 右栏：上移/下移/拖拽调顺序 → 设分值 → 分大题（一、选择题 / 二、计算题）
   ★ 注意右栏的「无答案 N 题」预警 —— 有题没答案会在这里提示
⑤ 进「导出」页 → 选答案模式（学生版/答案解析版）、模板（考试/测验/作业）、格式
⑥ 点「预览」→ 等几秒（首次要渲染，约 3–6 秒）→ 看到真实排版
⑦ 确认无误 → 点「导出」→ 得到 DOCX / PDF
⑧ 用 WPS 或 Word 打开 → 公式是可编辑的原生公式（不是图片）
```

**改题**：在「单题详情」页点编辑，可改题干、答案、解析、公式、章节/题型/难度/知识点。
**改完自动留旧版**——如果改错了，旧内容还在库里，可以找回。

## 四、必须知道的数据欠账

这些是**源资料本身的情况**，不是软件问题。界面会**如实显示**，不会粉饰。

| 情况 | 影响 | 怎么办 |
|---|---|---|
| **年级 82%、教材 82%、章节 64% 缺失** | **按年级筛选会漏题**（只能看到 1,342/7,945 题） | 用「来源文件」页逐份补；或**多用关键词检索**，不要只靠年级筛 |
| **难度 100% 为空** | 难度筛选暂时筛不出东西 | 在详情页逐题标注（易/中/难）；界面上显示为灰色「未标注」而不是空白 |
| **答案只覆盖 50%**（3,973/7,945） | 导出「答案解析版」时，没答案的题**只显示题干** | 组卷时看右栏「无答案 N 题」预警；导出预览会逐题标注 |
| **知识点是「提及」口径，不是「考查」** | 搜「压强」会出 2,378 道题，其中很多只是题干提到过 | 界面上标为「知识点（提及）」，**只当搜索线索用，不要当考查范围筛** |
| **196 条公式待复核** | 少数题的公式可能显示不全 | 在「待复核公式」页逐条看；不阻塞使用 |
| **419 道题的答案/解析里有取不到的公式** | 导出答案解析版时，这些位置会有提示 | 阶段1 数据抽取的遗留；可在详情页手工补 |

> **最重要的一句**：**不要只靠"年级/教材/章节"筛选找题**——因为大部分题没有这些标注，筛完会以为"题库里没有"，其实是"没标出来"。**关键词检索是可靠的**（7,945 题全量可搜，响应 6–13 毫秒）。

## 五、常见问题

**Q：关掉黑窗口后，浏览器打不开了？**
A：服务已停。重新双击 `启动题库.bat`。

**Q：导出很慢？**
A：首次预览要真实渲染（约 3–6 秒），**同内容再预览是秒回的**（有缓存）。改了题序才会重新渲染。

**Q：导出的公式在 WPS 里能改吗？**
A：能。导出的是**原生 OMML 公式**，Word 与 WPS 双端都实测可编辑（整卷 65 个公式逐个改字符→保存→重开，全部保留）。

**Q：改错了题怎么恢复？**
A：详情页有「版本历史」，能看到改了几版。旧内容在库里，需要时可用命令行找回（暂无回滚按钮）。

**Q：能让同事一起用吗？**
A：**当前版本不能。** 这是纯本地单机版，服务只跑在你自己电脑上。
多人共用需要先做服务端改造（原定"阶段5 异地访问"）——**特别注意：不要把 `outputs/bank.db` 放到共享盘上给多人同时用**，SQLite 在网络盘上会因文件锁不可靠而损坏。

## 六、技术信息（给维护者）

| 项 | 值 |
|---|---|
| 服务地址 | `http://127.0.0.1:8720`（仅本机） |
| 后端 | FastAPI + Uvicorn，43 个路径 / 49 个 API 操作 |
| 前端 | Vite + React + TypeScript + MUI + Tailwind + KaTeX |
| 数据库 | `outputs/bank.db`（SQLite 单文件，约 64 MB） |
| 启动入口 | `启动题库.bat` → `python -m webui` |
| 配置文件 | `outputs/webui/settings.json` |
| 导出产物 | `outputs/export/` |
| 预览缓存 | `outputs/webui/preview_cache/` |
| 自动化测试 | `python -m unittest discover -s tests`（360 项） |
| 接口文档 | 服务启动后 `http://127.0.0.1:8720/docs` |

**改题的安全性**：编辑会先备份当前内容到 `question_versions.snapshot_json`（含题干、公式、答案、解析），再写新版本。已出试卷有独立快照，**改题不会影响已导出的卷**。
