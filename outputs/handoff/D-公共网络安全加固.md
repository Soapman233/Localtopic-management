# 交接：公共网络安全加固（HTTPS + 日志脱敏）

> 日期：2026-10-12
> 角色：**D1**（实现）+ **T**（验收）
> 触发：用户反馈「**无法避免会在公司等公共网络进行使用**」

---

## 一、问题：原方案的暴露面

方案 A（局域网访问）默认是 **HTTP 明文**。在**公司/公共 WiFi** 下：

| 风险 | 说明 |
|---|---|
| 🔴 **令牌被嗅探** | 手机扫码链接是 `http://<ip>:<port>/?t=<令牌>`。WPA2-Personal（共享密码）网络下，**知道 WiFi 密码的人即可解密**你的流量 → 拿到令牌 = **完整读写权限** |
| 🔴 **令牌进日志** | uvicorn 访问日志默认记录完整 `request_line`，**令牌明文写入 `outputs/webui/start.log`**（已实测确认） |
| 中间人篡改 | 明文可被改写（题库内容被篡改） |

---

## 二、修复

### 2.1 HTTPS（自签证书）—— **根治嗅探**

| 要点 | 做法 |
|---|---|
| **私钥每机独立** | 证书在本机生成，只存 `outputs/webui/tls/`。⚠️ **绝不随程序分发同一份私钥**——那样嗅探者用公开私钥即可解密，加密形同虚设 |
| **SAN 含局域网 IP** | 含 `localhost` / `127.0.0.1` / 当前局域网 IP；**IP 变化时自动重建**（否则浏览器额外报"名称不匹配"） |
| **默认开启** | `network.https` 缺省 `True`；公共网络下明文等于把令牌交出去 |
| **优雅降级（但不静默）** | 缺 `cryptography` 时退回 HTTP，并**明确告警**「当前为明文传输，请勿在公共/公共网络使用」 |
| **证书警告要解释** | 自签证书**必然**触发浏览器"不安全"提示（除非在手机装根证书，对老师过重）。界面明确说明「点『继续访问』即可」，否则老师会被吓退 |

实现：`webui/services/tls_svc.py`（RSA 2048，有效期 825 天）+ `webui/__main__.py` 传给 uvicorn 的 `ssl_certfile`/`ssl_keyfile`。

### 2.2 日志脱敏 —— **令牌永不落盘**

`webui/__main__.py::_RedactQueryFilter` 挂在 uvicorn 的 `default` 与 `access` 两个 handler 上：

* 把访问日志里的 `?...` 统一替换为 `?<redacted>`；
* 兜底再对消息文本做 `?t=...` 正则替换。

**附带收益**：`/api/search?q=浮力` 之类的**检索词也不会进日志**（隐私）。

### 2.3 其他

* `network_status` 增加 `scheme` / `https` / `tls_available` / `cert_fingerprint`（供界面核对证书）；
* 新增 `POST /api/network/https` 开关；
* 修复启动提示：原先固定打印 `http://`，且**浏览器会打开错误的 http 地址**（局域网模式下还打印 `0.0.0.0`，不可浏览）——改为按实际协议 + 回环地址。

## 三、验收（打包版，**14/14 PASS**）

```
[步骤1] 默认仅回环；局域网地址访问 -> 连不上          ✅ 安全默认
[步骤2] 开启局域网 -> 返回链接（https://）与二维码     ✅
[步骤3] 重启 -> 自动监听全网卡 + HTTPS + 令牌
        局域网 /api/health（豁免）        -> 200
        🔴 同端口明文 HTTP                -> 握手失败   ✅ 嗅探拿不到令牌
        手机链接协议                      -> https://   ✅
        /api/papers 不带令牌 -> 401 / 带令牌 -> 200 / 错令牌 -> 401
        关闭局域网（带令牌）-> 200
[步骤4] 🔴 QB_HOST=0.0.0.0 且无令牌 -> **拒绝启动**（退出码 1）  ✅
```


## 五、给老师的说明（界面已内置）

1. 手机**首次**打开会提示「不安全 / 不是私密连接」——**这是正常的**（本机自签证书，没有花钱买域名证书）。
2. 点「**高级 / 显示详情**」→「**继续访问**」即可，之后不再提示。
3. **关闭加密会显著降低安全性**——界面用**红色**警示，且明确写出"同一网络下别人可以截获访问令牌"。

## 六、遗留与风险

| 项 | 说明 |
|---|---|
| **自签证书警告** | 无法消除（除非手机装根证书）。已用图文说明缓解 |
| **证书指纹** | 界面显示 SHA-256 前 16 位，供有经验的用户核对（防中间人替换证书） |
| **令牌仍是全权** | 手机丢失 → 设置页「更换访问令牌」；未做只读令牌 |
| **WPA2-Enterprise 网络** | 被动解密本就更难；HTTPS 后彻底不依赖网络加密强度 |
| **未做** | 客户端证书（mTLS）、只读令牌、访问审计日志 |
