## 一、做了什么

把 `bank.export.export_paper_docx` 从"**只能用桥接**"改为"**引擎可选**"，并把默认切到自研 `docx_writer`。

### 引擎

| 值 | 含义 |
|---|---|
| **`native`**（默认） | 自研 `bank.docx_writer`，**不依赖 `editor_sdk` / Office** |
| `bridge` | 原 `editor_sdk` 链路（保留为后备） |
| `auto` | 优先 native，失败时**回退 bridge 并如实记录** |

**选择优先级**：显式参数 `engine=` > 环境变量 `QB_EXPORT_ENGINE` > 默认 `native`。
新增 `resolve_export_engine()` 与 `DEFAULT_EXPORT_ENGINE` 常量（已导出）。

### 安全结构**未削弱**（两引擎共用）

```
渲染到 raw（临时） → 重建 payload 比对 content_digest → require_export_allowed → 发布到最终路径
```

* `native` 路径：`docx_writer.write_plan(plan, raw)` → 复核 → `os.replace(raw, out_path)`
* `bridge` 路径：`render_plan_to_docx(bridge, plan, raw)` → 复核 → `postprocess_bridge_docx(raw, dst=out_path)`

**"渲染期间内容变化则拒绝发布"这道闸门对两种引擎都生效**（原实现只覆盖 bridge）。

### 报告新增字段
`engine`（**实际生效**的引擎，而非请求值）、`bridge_warnings` / `bridge_errors`（native 时为空）。

## 四、过程中修正的 1 个测试（**重要，非削弱**）

切换默认引擎后，`test_cli_render_time_content_change_prevents_final_publication` **失败**：
它 mock 的是 `export.render_plan_to_docx`，而 native 路径走 `docx_writer.write_plan`，
于是"渲染期间改动内容"的模拟**没有生效**，闸门未被触发。

**处置**：**不是删掉或放宽这个测试，而是让它同时覆盖两种引擎**——
对 `native` mock `docx_writer.write_plan`、对 `bridge` mock `render_plan_to_docx`，
两者都必须抛 `ExportEvidenceStale` 且不产出最终文件。

> 该测试守护的是"**发布前复核**"这道安全闸门。默认引擎变了，闸门也必须跟着被验证，
> 否则就是**用一个未验证的路径替换了已验证的路径**。

## 五、一条方法论教训（如实记录）

验证"公式可编辑"时，我**第一次把 `engine_native.docx` 直接交给 Word 打开并保存**，
结果**污染了源文件**（公式被改成了 `Z`）。后续两次验证因此误报 `False`——
看起来像"WPS 不支持编辑"，实际是**我的验证脚本没有用副本**。

**修正**：每次验证都用 `shutil.copyfile` 复制独立副本。修正后双端均 PASS。

> 与项目既有铁律同源：**写入类验证必须用副本**。这次踩坑的是"验证脚本自己"。

## 六、遗留风险

| 风险 | 说明 | 建议 |
|---|---|---|
| **`auto` 会掩盖 native 缺陷** | native 失败静默回退 bridge，只看最终产物无法察觉 | 回退时已写入 `plan["warnings"]`；**生产环境建议显式用 `native`**，只在过渡期用 `auto` |
| **`bridge` 路径未回归** | 本次只跑通 1 份试卷 | 若长期保留 bridge，需补回归 |
| **PDF 导出仍依赖 Office** | `export_pdf` 未变（native 不产 PDF） | 便携版可考虑放弃 PDF 或降级 |
| **仅 1 份试卷验证** | 样本偏小 | Phase 3 前在更多试卷上重跑 |
| **CLI 未暴露 engine 参数** | `bank/cli.py` 仍用默认（现为 native） | 如需切换，用环境变量 `QB_EXPORT_ENGINE` |

## 七、给下游的输入摘要

`export_paper_docx(..., engine=None)` 现在**默认走自研引擎，不再需要 `editor_sdk`**；
`QB_EXPORT_ENGINE=bridge` 可切回旧链路。安全闸门（发布前复核）对两引擎均生效并有测试守护。
**便携客户端可以直接调用本函数，无需任何编辑器环境。**
