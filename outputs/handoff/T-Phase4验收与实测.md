## 二、4.1 环境隔离验证（**近似，非物理干净机**）

⚠️ **能力边界如实声明**：本机是**开发机**，装有 WorkBuddy / Python / Node / Office。  
所以做的是「**最小化环境变量**启动」——剥离 Python/Node/WorkBuddy 痕迹，  
这是"干净机器"的**近似**，**不等于**物理干净机。

**做法**：以仅 **14 个系统环境变量**启动（`SystemRoot`/`TEMP`/`USERPROFILE`… ），  
`PATH` **只含** `system32` 与 `SystemRoot`（**不含** python/node/workbuddy 目录），  
并确认 `PYTHONPATH`/`PYTHONHOME`/`NODE_PATH`/`CODEBUDDY`/`WORKBUDDY` 均**已剔除**。  
启动方式仍为 `DETACHED_PROCESS` + 不给任何 std 句柄（≈ 双击）。

**结果（4/4 PASS）**：

```
PASS  可启动            （就绪 1.65s）
PASS  health 正常        ok=True degraded=False
PASS  数据落在包内       outputs/bank.db 在 exe 旁
PASS  导入接口可用       /api/import/status -> 200
```

**说明**：exe 自带 Python 运行时（PyInstaller 打包），因此**不依赖系统 Python/Node**。
