# 版本分类（editions/）

本项目按**运行形态**拆分为两个版本。二者**共享同一套内核**，仅「运行方式 / 网络暴露 / 鉴权 / 部署形态」不同。

> **为什么共享内核而不是复制两份代码？**
> `bank/`（题库·组卷·导出）、`pipeline/`（DOCX 结构化）、`webui/`（API）、`frontend/`（界面）
> 是同一套业务逻辑。若复制成两份，修一个 bug 要改两处、跑两套测试，必然长期漂移。
> 因此这里采用**「一个内核 + 两个版本外壳」**：版本差异全部收敛到
> `webui/edition.py`（配置）与本目录下的启动/部署产物，**业务代码零分叉**。

---

## 一、总览

| 维度 | **本地运行版** `local/` | **线上部署版** `online/` |
|---|---|---|
| 目标使用者 | 一名老师，自己电脑 | 局域网 / 服务器上的多名教师 |
| 监听地址 | `127.0.0.1:8720`（仅回环） | `0.0.0.0:8720`（容器 / 服务器） |
| 访问范围 | 本机 | 内网 / 公网（需自行加固） |
| 鉴权 | 无 | nginx Basic Auth（浏览器）+ 可选 API 令牌 |
| 启动方式 | 双击 `启动题库.bat` | Windows 服务脚本 或 Docker Compose |
| 数据 | 本机 `outputs/bank.db` | 挂载卷持久化（`/data/bank.db`） |
| 导出能力 | ✅ 完整 | ✅ 完整（**须 Windows 宿主**，见下） |
| 适用人数 | 1 人 | 数人～十余人（受并发限制，见下） |

**共同点**：同一套前端、同一套 API、同一份题库格式、同一套测试（后端 373 项 / 前端 26 项）。

---

## 二、如何选择

- **只有你自己用** → `local/`。双击即用，无任何配置。
- **要给同办公室几位老师共用** → `online/`。见其 README 的部署步骤。
- **不确定** → 先用 `local/`，需要时再按 `online/` 部署（**两者数据格式完全一致**，`bank.db` 可直接搬运）。

---

## 三、切换版本（同一个内核）

版本由环境变量决定，**不需要换代码**：

```bash
# 本地版（默认，等价于不设置）
set QB_EDITION=local
python -m webui

# 线上版
set QB_EDITION=online
set QB_HOST=0.0.0.0
set QB_PORT=8720
python -m webui
```

| 环境变量 | 取值 | 说明 |
|---|---|---|
| `QB_EDITION` | `local` \| `online` | 默认 `local` |
| `QB_HOST` | IP | 缺省时 local→`127.0.0.1`，online→`0.0.0.0` |
| `QB_PORT` | 端口 | 默认 `8720` |
| `QB_AUTH_TOKEN` | 字符串 | **设置后**才启用 `/api/*` 的 Bearer 鉴权；不设置＝与历史行为完全一致 |

## 四、⚠️ 线上版的硬约束（务必先读）

1. **导出功能依赖 Windows 专有服务**。
   `bank/export.py` 通过 `editor_sdk`（本机 39099 端口）渲染公式、调用 Word/WPS 生成 DOCX/PDF。
   这些**只在 Windows 上可用** → **线上版必须部署在 Windows 宿主上**，否则导出会降级/不可用
   （检索、组卷、预览仍可用）。
2. **并发导出必须串行**。桥接服务为单实例，并发调用会报 `WinError 10048`（端口占用）。
   多人同时点「导出」会互相阻塞——这是**已知限制**，详见 `online/README.md`。
3. **鉴权仅为「访问控制」级**。当前是共享口令（nginx Basic Auth），
   **没有**「谁是谁 / 谁能改 / 谁能删」的用户与角色体系。适用于互相信任的小团队。

## 五、目录约定

```
editions/
├── README.md            ← 本文件（分类总览）
├── local/               ← 版本一：本地运行版
│   ├── README.md            使用说明（面向老师）
│   ├── 启动题库.bat          一键启动（可移植：BANK_PY > .venv > PATH）
│   └── settings.example.json 设置示例
└── online/              ← 版本二：线上部署版
    ├── README.md            部署指南（含硬约束与安全说明）
    ├── .env.example         环境变量模板
    ├── start-server.bat     Windows 宿主启动（推荐）
    ├── nginx.conf           反向代理 + Basic Auth
    ├── Dockerfile           （可选）Linux 容器，导出不可用
    └── docker-compose.yml   （可选）一键编排
```
