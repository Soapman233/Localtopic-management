# 对标产品调研：知识库 / 教案库 / 题库组卷系统

> 调研日期：2026-10-11
> 调研对象：本项目 = **私有题库（约 10 名中学教师，首个学科初中物理）→ DOCX 抽题 → 检索 → 组卷 → 导出公式可编辑试卷 → 本地/异地 Web**
> 说明：以下信息来自公开官网/仓库/评测文章，访问时间 2026-10-11；价格与合作条款以官方最新公示为准。

---

## 0. 结论速览（TL;DR）

| 判断 | 结论 |
|---|---|
| **最直接的对标赛道** | 国内 K12 **题库 + 组卷 + 校本题库**（学科网/组卷网、菁优网、二一教育） |
| **形态最接近本项目的产品** | **菁优网「校本题库」** 与 **学科网「题库管理系统 qbm.xkw.com」**——都是"私有题库 + 组卷 + 导出" |
| **内容组织方式最值得抄的** | **国家中小学智慧教育平台**（版块×场景）、**教习网/希沃**（教材版本→单元→课时） |
| **开源里最像本项目架构的** | **SurveyKing（卷王）**、**学之思 xzs**——都做"社区版开源 + 企业版私有化/源码授权" |
| **技术路线被独立验证** | **Pandoc** 走的就是"LaTeX → 原生 OMML"路线，与本项目定案**一致** |
| **本项目真正的差异点** | ① 内容源是**教师自有存量 DOCX**（供给侧 vs 平台供给）；② 交付形态是**可编辑 DOCX 试卷**而非在线考试；③ **Word + WPS 双端公式可编辑**为硬指标 |

## 9. 借鉴亮点清单（可直接落地）

### P0 · 建议优先
1. **"校本题库共建共享"机制**（学菁优网）：教师把认可的题加入"教研组精选题库"，并记录**贡献者**。本项目 `asset_manifest` 的 author 目前全为"待补充"，是明确缺口。
2. **内容导航四级化**：`教材版本 → 册/章节 → 知识点 → 题型`（学教习网 / 智慧教育平台）。本项目当前 `textbook` 有效 19%、`chapter` 25%，**导航前提是补齐元数据**。
3. **题目导入/导出标准**（学 Moodle GIFT）：定义本项目的题目交换格式（JSON/CSV），为未来"从其他平台迁题"留门。
4. **双版本交付模式**（学 SurveyKing）：社区/个人版与机构版分层——与本项目 `editions/local + online` 思路一致，可明确"授权/交付物"边界。

### P1 · 值得投入
5. **自动组卷算法**（学 TestPapaerGen）：在现有"手动加题"之上，增加"按章节/知识点/难度/分值自动抽题"（本项目 `difficulty` 当前全空，需先标注）。
6. **答案/解析绑定题**（学菁优网"全解全析"）：本项目已有 `answers.py`，可进一步做"解析独立成册"的导出模板。
7. **试卷版式模板化**（学商业产品的"试卷中心"）：学生版/教师版/答题卡/答案解析版四套模板。
8. **全文检索体验**（学 Outline/Wiki.js）：本项目已有 bigram+bm25，可补"高亮、筛选面板、相关题推荐"。

### P2 · 前瞻
9. **RAG 题库问答**（学 Dify/MaxKB/RAGFlow）：用向量检索支持"找类似的题""这题考什么"。注意 RAGFlow 的"深度文档理解"与本项目 DOCX 保真痛点同源。
10. **开放 API 化**（学学科网开放平台）：若未来服务多校，可把"检索/组卷/导出"做成 API。
11. **离线/弱网优先**（学 Kolibri）：支撑"异地访问"要求。

## 10. 差异点与风险（必须清醒）

| 维度 | 对标产品 | 本项目 | 影响 |
|---|---|---|---|
| **内容供给** | 平台方供给千万级题库 | **教师自有存量 DOCX（209 份/7945 题）** | 规模小，但**贴合本校真实教学**；护城河是"自有资料数字化" |
| **交付形态** | 在线答题 / 网页试卷 / PDF | **可编辑 DOCX（Word+WPS 双端）** | ★ 核心差异；也是最大技术难点（已攻克旧式公式） |
| **公式处理** | 多用 MathType 对象 / 图片 / 网页渲染 | **原生 OMML（不依赖第三方）** | ★ 本项目独有优势；Pandoc 独立验证路线正确 |
| **考试/阅卷** | 普遍具备（扫描阅卷、学情分析） | **不做** | 需明确"本项目不是考试系统"，避免用户预期错位 |
| **多用户/权限** | 校级 RBAC、机构账号 | **约 10 人，当前无认证代码** | 团队化落地前必须补权限（当前 `webui/` 零认证） |
| **部署/异地** | 云 SaaS 开箱即用 | 仅绑 `127.0.0.1`，需自行解决异地 | 与"异地访问"硬要求冲突，是上线阻塞项 |
| **移动端** | 普遍有 App/小程序 | 无 | 教师移动批阅/查看场景缺位（可选未来） |
| **内容质量背书** | 专业团队审校（如菁优 1000+ 人更新） | 无审校流程，靠教研组 | 可引入"复核队列"（本项目已有 `review.py`，196 条待复核） |
