## 一、术语中文化（P0-1）

### 1.1 新增 `frontend/src/lib/glossary.ts` —— 术语映射的**唯一来源**

与 `api/errors.ts`、`api/queryKeys.ts` 同样的定位：**不在调用处拼字符串**，而是调用语义函数
（`describeLockedSnapshot()`、`describeExportGate(state)`、`describeSnapshotStale(count)`…）。

### 1.2 映射表

| 旧文案（开发者视角） | 新文案（教师视角） |
|---|---|
| 快照锁定 | 本题在题库中已更新，本卷仍用加入时的版本（按钮：**更新到最新**） |
| 降级解锁 / 已确认结构预览（降级解锁） | 当前电脑未安装 Word/WPS，已改用结构预览确认 |
| 门禁已解锁（像素预览为当前内容） | 预览已确认，可以导出 |
| 导出已锁定（需先生成像素预览） | 导出已锁定，请先生成并确认预览 |
| 修订候选 | 导出前需要处理的问题 |
| 提及口径 | 这是搜索线索，不代表本题考这个知识点 |
| 技术详情 | 给技术人员的信息 |

### 1.3 原始技术字段退到 debug 开关后

## 二、导航分组与信息架构（P0-4 / P1-6）

### 2.1 新结构

```
[顶部] 初中物理 · 题库与组卷

日常备课（高频）
  ● 组卷工作台    /builder     ← 默认落地页
  ○ 找题          /search
  ○ 导出中心      /export

数据治理（低频）
  ○ 知识点复核    /manage/knowledge
  ○ 公式复核      /manage/formula-review
  ○ 来源文件      /manage/sources
  ○ 题库统计      /manage/stats

[底部] 系统设置    /settings
```

- 分组标题用 `ListSubheader`（**非可聚焦**，不进 Tab 序列）；
- 标题去掉技术词：`题库 Web 界面 · 初中物理` → **`初中物理 · 题库与组卷`**
  （`index.html` 的 `<title>` 也一并改了）。

### 2.2 默认落地页

`/` 与未知路径统一落到 **`/builder`**（常量 `DEFAULT_LANDING_PATH`）。
理由：老师的最高频动作是**组卷**，原先落到 `/search` 等于每次多一跳。

### 2.3 旧链接兼容（**关键**）

治理页迁移会让老师的旧书签失效，因此用 `LEGACY_REDIRECTS` 做重定向：

| 旧路径 | 新路径 |
|---|---|
| `/#/knowledge` | `/#/manage/knowledge` |
| `/#/formula-review` | `/#/manage/formula-review` |
| `/#/sources` | `/#/manage/sources` |
| `/#/stats` | `/#/manage/stats` |

重定向注册在 `*` 通配**之前**（顺序很重要，否则会被通配吞掉）。已实测 4 条全部生效。

## 三、难度死功能处理（P0-5）

**问题**：`difficulty` 全库 **100% 未标注**（实测 `items=0`、`missing=818`、覆盖率 **0.0%**），
但筛选栏仍提供「难度」维度 → 老师点了**筛不出任何结果**，会误判成「系统坏了 / 题库没题」。

**修法（做成通用判定，不只针对难度）**：

| 改动 | 效果 |
|---|---|
| `FilterSidebar` 新增 `dimensionUsable(bucket)` | 任何「无可用取值」的维度（`items` 为空）→ 标**「暂不可用」**、默认折叠、说明原因与出路，**不再渲染死按钮** |
| 带旧筛选时提供「清除该筛选」 | 不会卡在一个筛不出结果的维度上 |
| `CoverageBanner` | 覆盖率 0 的维度显示**「未标注（N 题）」**而非「0%」——0% 会被误读成"统计坏了" |
| `StatsPage` | 原本已如实标注「难度（100% 未标注）」，**无需改** |
