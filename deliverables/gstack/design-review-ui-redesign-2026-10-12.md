## 1. 各成员核心结论

### 🎨 设计顾问（视觉评审，**已实拍 30 张截图**）
- **核心判断**：三个共性问题——① **界面在向老师解释系统**（导出页顶部整段架构说明，甚至把 `**全屏预览 / 导出历史**` 的星号**直接渲染到屏幕上**）；② **多列 + 多条横幅叠放的"控制台感"**（组卷页一屏 4 列，检索页结果上方最多 5 条横幅，主角被挤到折叠线下）；③ **内部/调试信息泄漏**（`LivePreviewPanel.tsx:336` **无条件**渲染「测量 0.20ms · 重排 v1」，而该文件其它 debug 都有开关）。
- **关键建议**：整体设计语言定为「**内容优先的工具型极简**」——**一屏一个主角**，其余降为可展开的次要层；系统状态用"安静的状态点"而非横幅；解释性文字全部退到帮助。
- **它明确要求保留的**：`theme.ts` 单一 token + 65/65 对比度门禁（深色一致，**别重做**）、四态组件、组卷页 1366 双栏（"边组边看"是刚需，**别因"看着挤"就默认折叠**）、无障碍基线、深色观感。

### 🔍 产品评审员（信息架构与交互简化）
- **核心判断**：**"太像控制台"的根源是把建库期的一次性页面摆在了老师每天要用的地方**——来源文件/统计/两个复核页与检索、组卷**同级占导航**（`App.tsx:82-90`）。
- **关键发现**：导出页有**两个「生成预览」按钮**（`ExportPage.tsx:237-244` 与 `:258-267`）；检索页把 `/api/search`、`has_answer` **字段名讲给老师听**（`SearchPage.tsx:332-336`）；知识点复核页有 **32,936 项待复核**（截图实测），**逐条人工根本不可行**。
- **关键建议**：侧栏 **10 项 → 3 项 + 1**；并给出 3 个**不增加学习成本**的创新点（一句话组卷 / 右栏只留 A4 纸面 / 一个「数据健康度」圆环）。
- **它坚持保留的复杂度**：强制预览门禁（`useExportGate`）、文件级元数据影响预检（改一题=改整份文件全部题）、知识点「提及口径」说明、快照锁定。

### 🔧 调查员（设计参考与资源调研）
- **核心判断**：**不要换组件库**——MUI 已与 token 体系、对比度门禁、无障碍基线深度绑定，换库 = 10 页 + 27 组件重写，**估数周**，而设计感可由**用法**获得。
- **关键发现**：`motion` 组件 **34KB 且无法 tree-shake**（会把刚做完的代码分割吃回去）；`tremor` 依赖 Tailwind（已移除），引入会**复活第二套 token**；当前 `src` 里**只有 4 处 transition**，动效基建几乎为零。
- **关键建议**：**AutoAnimate（~2.5KB）+ View Transitions API（0KB 原生）** 起步；借鉴 **Notion 渐进披露** + **Linear 对齐克制**。
- **skill 结论**：现有 4 个设计 skill 够用，SkillHub 上的替代品**高度重叠、建议不装**。

## 4. 设计方案（三方共识）

### 设计语言：**内容优先的工具型极简**
> 一屏一个主角，其余降为可展开的次要层；系统状态用"**安静的状态点**"而非横幅；解释性文字全部退到帮助。

**为什么适合这批用户**：不会命令行、每天只做找题/组卷/导出 3 件事、主机型 1366×768 **横向极紧** → 必须减少"同时可见的元素数"。

### 资源选型（**零组件库迁移**）

| 项 | 决定 | 理由 |
|---|---|---|
| MUI 5 | **保留** | 与 token/对比度门禁/无障碍深度绑定；换库数周且收益不抵 |
| **AutoAnimate** | **引入（~2.5KB）** | 列表/抽屉增删过渡；纯 hook 零冲突 |
| **View Transitions API** | **引入（0KB 原生）** | 路由级切换；渐进增强 |
| 纯 CSS transition | 首选 | 项目 `index.css:43` 已有全局 reduce 块 |
| `motion` / `tremor` | **排除** | 34KB 不可 tree-shake / 依赖已移除的 Tailwind |
| `@mui/x-charts` | **待评估体积后再定** | 与 MUI theme 同源，可替代手搓 `LinearProgress` 条形 |

⚠️ **动效硬约束**：必须支持 `prefers-reduced-motion`（项目已有全局 reduce 块 + 无障碍基线）；**不得让首屏回退**（当前入口 30.8KB）。

### 三个创新点（**不增加学习成本**）
1. **一句话组卷**：首页一个输入框（"八年级浮力，10 选择+2 计算"）→ 出草稿卷，把检索→筛选→加入→设分 **4 步压成 1 步**（概念不新增，只是把已有能力前置）
2. **右栏只留 A4 纸面视图**：合并"排版/清单"，所见即所得直编
3. **一个「数据健康度」圆环**：把散在 4 页的覆盖率/复核进度收成 1 个入口，替代说教型 Alert
